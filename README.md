# OpenSelection

A standalone, robust, Swift 6 selection retrieval engine for macOS (macOS 14+).

`OpenSelection` extracts the currently selected text, selection screen bounds, rich representations (HTML, RTF), and source application information from *any* active macOS application. It handles native Cocoa controls, WebKit web areas, Chromium/Electron webviews, terminal emulators, PDF viewers, and Microsoft Office documents using a multi-tiered, deadline-bounded cascade.

ZERO third-party dependencies — built entirely on Apple system frameworks (`AppKit`, `ApplicationServices`, `CoreGraphics`, `os.log`) with Swift 6 complete concurrency checking (`SWIFT_STRICT_CONCURRENCY: complete`).

---

## Features

- **Multi-tiered Strategy Cascade**:
  - `AXTextControlStrategy`: Direct zero-copy accessibility reads for native text fields (`AXTextField`, `AXTextArea`).
  - `AXWebAreaStrategy`: Text marker range inspection and bounded settle-retries for WebKit web content.
  - `menuCopy`: Non-invasive menu item traversal triggering `Edit ▸ Copy` via Accessibility.
  - `keyboardCopy`: Synthetic ⌘C dispatch with pre-flight enablement checks, pasteboard snapshot archiving, and transient marker restoration.
  - `officeScript`: AppleScript Object Model retrieval for Microsoft Office (Word, Excel, PowerPoint) avoiding clipboard pollution.
- **Watchdog Deadlines & Concurrency Gating**:
  - All accessibility inspects run off the cooperative thread pool on a dedicated concurrent queue.
  - Hard timeouts (`axReadTimeout: 0.5s`, `pasteboardCopyTimeout: 0.25s`) ensure slow or hung target apps never block the caller.
  - Concurrency permit gate bounds in-flight inspects and menu presses to prevent thread pool exhaustion.
- **Rich Content Enrichment**:
  - Automatically captures rich representations (`public.html`, `public.rtf`) for web content and formatted documents.
- **Clipboard Preservation**:
  - `PasteboardSnapshot` captures and restores clipboard items tagged with `org.nspasteboard.TransientType` and `org.nspasteboard.AutoGeneratedType`, preventing third-party clipboard managers from logging transient copies.
- **Context & Cursor Gating**:
  - Role-based gates prevent firing copies on row selections (e.g. Finder file rows, Mail message lists) or non-text controls (`AXButton`, `AXSlider`).
  - Cursor silhouette analysis (`CursorClassifier`) identifies beam, arrow, and pointing hand cursors to filter non-text contexts.

## Quickstart

### Retrieve Plain Text

```swift
import OpenSelection

if let text = await OpenSelection.selectedText() {
    print("Selected text: \(text)")
}
```

### Retrieve Full Selection Details

```swift
import OpenSelection

if let result = await OpenSelection.current() {
    print("Text: \(result.text)")
    if let bounds = result.bounds {
        print("Screen bounds: \(bounds)")
    }
    if let html = result.html {
        print("HTML: \(html)")
    }
    print("Strategy used: \(result.strategy)")
    print("Source app: \(result.sourceApp?.localizedName ?? "unknown")")
}
```

### Custom Configuration

```swift
import OpenSelection

var config = SelectionConfiguration.default
config.axReadTimeout = 0.3
config.pasteboardCopyTimeout = 0.2

let result = await OpenSelection.retrieve(
    configuration: config,
    allowCopyFallback: true
)
```

### Pluggable Logging

```swift
import OpenSelection

OpenSelection.logger = { message in
    print("[CustomLog] \(message)")
}
```

## Retrieval Strategies Explained

| Strategy | Description | Best For |
|---|---|---|
| `.axTextControl` | Direct AX query (`kAXSelectedTextAttribute` / `kAXValueAttribute`) | Native Cocoa apps (TextEdit, Notes, Pages, Finder dialogs) |
| `.axWebArea` | WebKit text marker ranges (`AXSelectedTextMarkerRange`) with settle retries | Safari, Mail web bodies, WebKit webviews |
| `.officeScript` | AppleScript Object Model document selection extraction | Word, Excel, PowerPoint |
| `.menuCopy` | Locates and presses `Edit ▸ Copy` via AX menu hierarchy | Apps with disabled keystroke taps or custom menus |
| `.keyboardCopy` | Verifies `Edit ▸ Copy` enablement, archives pasteboard, fires ⌘C, captures result, restores pasteboard | Chromium, Electron (VS Code, Slack), Terminal, Ghostty |

## Edge-Case Guarantees

1. **Unresponsive App Protection**: If an application hangs on an AX request or beachballs, the worker continuation resumes with `nil` after the deadline (`axReadTimeout`).
2. **Clipboard Manager Transparency**: Any temporary copy made during `.keyboardCopy` or `.menuCopy` is immediately restored with transient markers so Raycast, Alfred, Maccy, and Paste don't record ghost entries.
3. **Office Document Clipboard Safety**: Blind ⌘C keystrokes are never fired against Microsoft Office apps; selection is retrieved via the native AppleScript object model.
4. **Row-Selection Safety**: Select-all (⌘A) gestures on tables, outlines, and lists (Finder files, Mail thread list) are recognized and skipped to prevent copying file lists as plain text.
